## Tag2Text/RAM/RAM++

OpenFunGraph 里面用到了这个系列的工作：

> 对于每张 RGB 图像，首先使用 RAM++ 进行开放图像识别。这一步不输出位置，只输出一组类别标签，然后将这些类别标签作为提示词输入 GroundingDINO

在原有的 VLM 的基础上，Tag2Text 认为自然语言的 caption 太复杂，所以在 image 和 caption 之间加了一个更加结构化的中间表示 tag。

可以理解为使用 tag 作为视觉-语言之间的语义桥梁。

但是，在 Tag2Text 中，一个 tag 对应的 embedding 在构造的时候，并不含有这个 tag 对应的语义。这导致这些 embedding 面对 unseen categories 时缺乏语义联系。所以在 RAM 中 embedding 则通过  CLIP text Encoder 构造。

RAM 的 query 虽然是 open 的，但是训练仍然是 close 的。RAM++ 在训练时就加入了完整的文本监督，以及使用 LLM 给每个类别生成大量视觉描述。

## FunFact

和 OpenFunGraph 一样，都是生成功能 3D 场景图。

整体流程可以分为两部分。

- 第一部分：Scene Reconstruction

  - 输入：RGB image，Depth，camera pose
  - 先使用 VLM 分析每张图片，例如看到 stove，VLM 可能提出：

  ```
  stove
  ├── knob
  ├── burner
  └── oven handle
  ```

  - 这一步建立了 Object -> Parts 这一显示结构。
  - 为了解决 VLM 的幻觉问题，在此之后作者进行了 grounding。首先 VLM 提出：“这里可能有一个 cabinet，它可能有 handle。”然后 GroundingDINO 真正在图像中定位 cabinet bbox，再在 cabinet crop 内部寻找 handle bbox，最后用 SAM 得到 mask。作者还会根据 part 与 parent object 的尺寸比例和重叠关系过滤错误检测。
  - 然后结合 RGB-D 和 camera pose，把不同视角中的 mask back-project 到 3D，并进行 multi-view fusion。最终得到的是一个 Object 3D map。
  - 可以理解为：

  ```
  Scene
  ├── Stove
  │   ├── knob_1
  │   ├── knob_2
  │   ├── burner_1
  │   └── burner_2
  │
  ├── Cabinet
  │   └── handle
  │
  └── Lamp
      └── switch
  ```

- 第二部分：Function Reasoning

  - 得到这些 Object / part node 之后，作者再问 LLM 这些部件是什么关系，同时判断这些关系是一对一的还是一对多/多对一的。这种常识后续会转化为 Factor Graph 中的结构约束。

  - 怎么建立 node 之间的边呢？论文提出了一种叫 Dual Factor Graph 的方法：

  - 假设：

    ```
    knob1
    knob2
    
    
    burner1
    burner2
    ```

    单纯从语义上看，可能有：

    ```
    knob1 → burner1
    knob1 → burner2
    knob2 → burner1
    knob2 → burner2
    ```

    也就是四条 candidate functional edges。

    传统方法可以分别问：
    $$
    P(e_1),P(e_2),P(e_3),P(e_4)
    $$
    问题在于四个判断彼此独立。

    FunFact 则把**每一条可能存在的 functional edge 变成一个二值随机变量**：
    $$
    x_i=
    \begin{cases}
    1 & \text{relation exists} \\
    0 & \text{otherwise}
    \end{cases}
    $$
    也就是说：

    ```
    x1 = knob1 → burner1 ?
    x2 = knob1 → burner2 ?
    x3 = knob2 → burner1 ?
    x4 = knob2 → burner2 ?
    ```

    原 Scene Graph 中的 edge，现在变成 Factor Graph 中的 variable，因此作者称它为 **Dual Factor Graph**。
