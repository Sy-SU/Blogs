可以把 affordance 理解为：

> 一个物体或环境，在特定主体和当前状态下，“允许你做什么”。

在机器人和 3D 场景里，通常翻译成“可供性”或“可交互性线索”。

比如看到一个杯子：

- 它是“杯子”——这是 semantic / category。
- 它在桌子上——这是 relationship。
- 它可以被抓起来、拿取、装水——这是 affordance。

所以三者关注的问题不同：

| 信息         | 回答的问题                 | 杯子的例子           |
| ------------ | -------------------------- | -------------------- |
| Semantic     | 它是什么？                 | cup                  |
| Relationship | 它在哪里、和谁有什么关系？ | cup ON table         |
| Affordance   | 可以对它做什么？           | grasp, pick up, pour |
| Articulation | 它自身哪些部分怎么运动？   | 杯子通常没有关节     |

最重要的一点是：**affordance 不完全等于物体的固定属性。**

比如“椅子可以坐”听起来像物体属性，但严格来说 affordance 是“主体—物体—环境”之间的一种关系。

同一个物体，对于不同主体，可以有不同 affordance。

例如一张很高的桌子：

- 对成年人：可以放东西；
- 对小孩：可能够不到；
- 对移动机器人：可能可以从下面穿过；
- 对机械臂：如果超出工作空间，就不可抓取。
