  ```

  ```
  Need water

  Navigate(refrigerator)

  ```
  VLM:

  ```

  ```

      revolute joint

  ```

  motion planner：

  ```
  reach handle
  grasp
  rotate around hinge
  ```

  打开以后重新观察：

  ```
  VLM:
  water bottle on second shelf
  ```

  再执行：

  ```
  grasp bottle
  ```

## 笔记

VLM 怎么理解整个室内场景，进行任务规划与交互？

怎么把像素转换为语义？

例如 relationship 与 affordance（怎么获取呢？）

如何表示一个场景？

**Scene Graph**

```
Room
├── Table
│   ├── Cup
│   └── Plate
│
├── Cabinet
│   ├── Door
│   └── Drawer
│
└── Refrigerator
    └── Door
```

以及关系：

```
Cup --ON--> Table
Cabinet --RIGHT_OF--> Table
CabinetDoor --PART_OF--> Cabinet
CabinetDoor --OPENABLE-->
```

任务规划？

例如，让机器人完成某个任务：把桌上的杯子放进柜子里

VLM 首先利用场景信息进行 reasoning：

```
Goal:
cup INSIDE cabinet
```

当前状态：

```
cup ON table
cabinet CLOSED
robot NEAR table
```

目标状态：

```
cup INSIDE cabinet
```

于是可以推理出：**（怎么推理出来的？）**

```
1. approach cup
2. grasp cup
3. approach cabinet
4. open cabinet
5. place cup inside cabinet
6. release cup
```

真正执行交互时，VLM 还远远不够

比如 VLM 输出：

> Open the cabinet.

对机器人来说，这句话几乎没有直接执行价值。

机器人真正需要知道：

```
cabinet door handle position
door hinge position
hinge axis
opening direction
joint limits
collision geometry
grasp pose
trajectory
```

也就是说：

\[ \text{Semantic action} \neq \text{Executable action} \]

从：

```
Open cabinet
```

到真正机器人动作之间还有一整层：

\[ \text{Task Planning} \rightarrow \text{Skill Planning} \rightarrow \text{Motion Planning} \rightarrow \text{Control} \]

例如：

```
Open(cabinet)
```

展开成：

```
detect cabinet door
        ↓
detect handle
        ↓
estimate hinge
        ↓
move end-effector to handle
        ↓
grasp handle
        ↓
generate constrained trajectory
        ↓
rotate around hinge axis
```

因此可以把系统分成三个尺度。

高层：VLM / LLM

处理：

```
What is here?
What does the human want?
What should I do next?
```

例如：

```
Pick up the cup.
Open the cabinet.
Put the cup inside.
```

中层：Skill / Affordance

处理：

```
How can this object be interacted with?
```

例如：

```
Grasp(cup)
Open(cabinet_door)
Pull(drawer)
Push(button)
```

低层：Robot Controller

处理：

```
Where should the robot move?
```

最终是：

\[ q_t,\dot q_t,\tau_t \]

也就是机械臂的：

- joint position
- velocity
- torque
